# R Data Visualization Projects

A collection of data visualization and exploratory analysis projects built in R,
using APIs, web scraping, and publicly available datasets.

## Projects


- League of Legends ARAM Stats
- Women's 400m Hurdles Records
- TV Drama Wordiness Web Scraping
- [Strava Running Analysis](https://medium.com/@michaelj.yu24/patterns-and-paces-insights-from-my-running-journey-d3b6d3d6c2fb)

## Tools & Technologies

- R
  - ggplot2
  - dplyr
  - tidyr
  - APIs (httr, jsonlite)
  - Web scraping (rvest)
